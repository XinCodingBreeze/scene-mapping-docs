外观

Scene Mapping GIS让二维与三维场景快速落在业务里

一套 Vue 3 + TypeScript 组件库，同时覆盖 Leaflet 2D 地图与 Cesium 3D 场景。

反馈问题

多地图源

2D 支持天地图、OpenStreetMap 与自定义 XYZ；3D 支持 XYZ、TMS、WMTS 与 Cesium ion。

业务区域编辑

绘制、编辑、删除多边形，并支持洞、岛、净面积和自定义业务字段。

标准化数据

使用清晰的二维与三维坐标类型，通过 v-model、事件与公开方法对接业务系统。

实时示例

2D 文档内可直接操作地图，3D 提供完整 Demo 与可复制的 Cesium 场景代码。
