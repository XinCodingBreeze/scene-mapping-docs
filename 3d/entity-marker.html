实体与业务标记 ​

CesiumEntity ​

适合声明式维护少量独立实体。组件支持 billboard、label、point 和 description，并响应位置及展示属性变化。

vue
<CesiumEntity
  :longitude="121.4737"
  :latitude="31.2304"
  :height="300"
  name="上海外滩"
  description="业务详情"
  :point="{ pixelSize: 16, color: Color.BLUE }"
  :label="{
    text: '上海 · 外滩',
    fillColor: Color.WHITE,
    outlineColor: Color.BLACK,
    outlineWidth: 2,
  }"
/>

Props ​

名称类型说明
longitudenumber必填，经度（度）
latitudenumber必填，纬度（度）
heightnumber高度（米），默认按 0 使用
namestringEntity 名称
billboardBillboardGraphics.ConstructorOptions图标配置
labelLabelGraphics.ConstructorOptions标签配置
pointPointGraphics.ConstructorOptions点配置
descriptionstring信息框描述

组件卸载时只移除自己创建的 Entity。

CesiumDropMarker ​

适合以数组批量渲染业务点位，并在点击后将原始业务数据和屏幕坐标交给外部弹窗。

vue
<CesiumDropMarker
  ref="markerRef"
  :points="markerPoints"
  :label-style="{ pixelOffset: [0, 48], outlineColor: '#ff551e' }"
  @click="onMarkerClick"
  @position-update="popupPosition = $event"
/>
ts
const markerPoints: MarkerPoint[] = [{
  id: "site-001",
  longitude: 116.4074,
  latitude: 39.9042,
  height: 0,
  image: markerImage,
  text: "北京站点",
  status: "online", // 自定义业务字段会被保留
}];

Props ​

名称类型默认值说明
pointsMarkerPoint[]必填业务点位数组
defaultImagestring内置图标点位未传 image 时使用
iconWidthnumber32图标宽度
iconHeightnumber47图标高度
showLabelbooleantrue是否显示文字
labelStyleMarkerLabelStyle{}组件级标签样式

标签样式优先级为：内置默认值 → 组件 labelStyle → 点位 labelStyle → 兼容字段 labelColor。

事件与方法 ​

  • click(point, screenPosition)：点击 Marker，返回原始点位和 { x, y }。
  • position-update(screenPosition)：相机变化时返回已选中 Marker 的新屏幕位置。
  • clearSelection()：停止跟踪当前选中 Marker。

弹窗属于业务 UI，应放在 CesiumMap 外部的定位容器中，通过屏幕坐标定位。
