3D · CesiumImagery 影像图层 ​

3D 文档 · CesiumImagery 组件

CesiumImagery 在父级 CesiumMap 中创建并管理影像图层，支持 XYZ、TMS、WMTS 和 Cesium ion。

公开影像示例 ​

vue
<CesiumImagery
  type="xyz"
  url="https://server.arcgisonline.com/arcgis/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}"
  :options="{ maximumLevel: 18 }"
  :show="true"
  :alpha="1"
/>

本站演示使用公开的 ArcGIS World Imagery。该地址需要外网访问，生产环境应确认服务授权、限额和可用性。

Props ​

名称类型默认值说明
type'xyz' | 'tms' | 'wmts' | 'ion' | 'default'defaultProvider 类型
urlstring—XYZ、TMS 或 WMTS 服务地址
assetIdnumber1Cesium ion 影像资源 ID
showbooleantrue图层显隐
alphanumber1透明度，范围 0–1
optionsRecord<string, any>—Provider 原生配置

type、url 或 assetId 改变时会重建图层；show 和 alpha 只更新现有图层。组件卸载时只移除自己创建的图层。

WMTS 示例 ​

vue
<CesiumImagery type="wmts" :url="wmtsUrl" :options="{
  layer: 'img', style: 'default', format: 'tiles',
  tileMatrixSetID: 'w', maximumLevel: 18,
}" />
