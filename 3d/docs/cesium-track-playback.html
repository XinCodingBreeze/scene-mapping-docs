Cesium 3D · 轨迹回放 ​

3D 文档 · 时间采样、进度控制与相机跟随

CesiumTrackPlayback 使用 Cesium 时间系统驱动车辆或人员沿轨迹移动。组件只管理地图实体和播放状态，控制栏、业务详情等 UI 由使用方自由实现。

基础用法 ​

vue
<CesiumMap @load="viewerRef = $event">
  <CesiumTrackPlayback
    ref="playbackRef"
    :points="trackPoints"
    :duration="60"
    :speed="1"
    :follow="false"
    :follow-offset="[0, -3200, 3200]"
    @progress="onProgress"
    @finish="onFinish"
  />
</CesiumMap>
ts
const trackPoints = [
  { longitude: 117.638, latitude: 39.022 },
  { longitude: 117.693, latitude: 39.021 },
  { longitude: 117.744, latitude: 39.015 },
];

playbackRef.value?.play();
playbackRef.value?.pause();
playbackRef.value?.seek(0.5);
playbackRef.value?.setSpeed(2);

不传 time 时，轨迹点会在 duration 内均匀分布。需要还原真实采集间隔时，可以给每个点传相对秒数或绝对时间：

ts
const points = [
  { longitude: 117.638, latitude: 39.022, time: 0 },
  { longitude: 117.693, latitude: 39.021, time: 8 },
  { longitude: 117.744, latitude: 39.015, time: 21 },
];

Props ​

名称类型默认值说明
pointsCesiumTrackPoint[]必填至少两个轨迹点
durationnumber60未传时间时的总时长，单位秒
speednumber1播放倍速
autoplaybooleanfalse初始化后自动播放
loopbooleanfalse是否循环播放
followbooleanfalse是否使用 Cesium trackedEntity 跟随
followOffset[number, number, number][0, -3200, 3200]跟随视角的左右、前后和高度偏移，单位米
showRoutebooleantrue显示完整轨迹线
showTravelledbooleantrue显示已行驶轨迹
routeColorstring半透明绿色完整轨迹颜色
travelledColorstring#ffb84d已行驶轨迹颜色
routeWidthnumber4轨迹线宽度
markerImagestring内置方向图标移动实体图标
markerSizenumber42移动图标尺寸
markerLabelstring巡检车辆移动实体标签

方法与事件 ​

组件 ref 提供 play()、pause()、reset()、seek(progress)、setSpeed(speed)、setFollow(follow) 和 getState()。

ready 返回完整控制器；play、pause、progress、finish 返回 CesiumTrackPlaybackState；输入坐标或时间无效时触发 error。

Viewer 时钟

组件挂载时会暂时接管当前 Viewer 的时钟；卸载时会恢复原来的开始时间、结束时间、当前时间、倍速、循环模式和播放状态。同一个 Viewer 建议同时只挂载一个轨迹回放组件。
