3D · 实体与业务标记 ​

3D 文档 · 声明式实体、批量标记与实体管理

三套 API 面向不同场景：少量独立对象使用 CesiumEntity，业务点位列表使用 CesiumDropMarker，大量动态对象的命令式增删改查使用 useEntityManager。

CesiumEntity：声明式点、线、面 ​

完整使用方式 ​

先从 Cesium 引入坐标和颜色工具，然后把配置对象传给 CesiumEntity：

vue
<template>
  <CesiumMap @load="viewerRef = $event">
    <!-- 点 -->
    <CesiumEntity
      :position="[121.4737, 31.2304, 300]"
      name="上海外滩"
      :point="pointOptions"
      :label="labelOptions"
    />

    <!-- 线 -->
    <CesiumEntity name="巡检路线" :polyline="polylineOptions" />

    <!-- 面 -->
    <CesiumEntity name="业务地块" :polygon="polygonOptions" />
  </CesiumMap>
</template>

<script setup lang="ts">
import { shallowRef } from "vue";
import { Cartesian2, Cartesian3, Color, LabelStyle } from "cesium";
import { CesiumEntity, CesiumMap } from "scene-mapping-gis/3d";
import type { Viewer } from "cesium";

const viewerRef = shallowRef<Viewer | null>(null);

const pointOptions = {
  pixelSize: 16,            // 点的直径，单位 px
  color: Color.RED,         // 填充颜色
  outlineColor: Color.WHITE,
  outlineWidth: 3,
};

const labelOptions = {
  text: "上海 · 外滩",
  fillColor: Color.WHITE,
  outlineColor: Color.BLACK,
  outlineWidth: 3,
  style: LabelStyle.FILL_AND_OUTLINE,
  pixelOffset: new Cartesian2(0, -28),
};

const polylineOptions = {
  // 按“经度, 纬度”依次填写路径节点
  positions: Cartesian3.fromDegreesArray([
    121.45, 31.22,
    121.48, 31.24,
    121.50, 31.23,
  ]),
  width: 6,                 // 线宽，单位 px
  material: Color.CYAN,     // 线颜色
  clampToGround: true,      // 是否贴地
};

const polygonOptions = {
  // 按“经度, 纬度”依次填写边界点，Cesium 会自动闭合
  hierarchy: Cartesian3.fromDegreesArray([
    121.45, 31.22,
    121.50, 31.22,
    121.50, 31.18,
    121.45, 31.18,
  ]),
  material: Color.ORANGE.withAlpha(0.5), // 半透明填充
  outline: true,
  outlineColor: Color.ORANGE,
};
</script>

CesiumEntity 顶层属性 ​

属性实际传值默认值用途
position[经度, 纬度, 高度?] 或 { longitude, latitude, height? }—点、图标和标签的位置
longitudenumber—兼容写法：经度
latitudenumber—兼容写法：纬度
heightnumber0兼容写法：高度，单位米
idstringCesium 自动生成实体唯一 ID
showbooleantrue是否显示实体
namestring—实体名称
descriptionstring—点击实体时使用的描述内容
point下方 point 配置对象—显示圆点
label下方 label 配置对象—显示文字
billboard{ image, width?, height?, ... }—显示图片图标
polyline下方 polyline 配置对象—显示线
polygon下方 polygon 配置对象—显示面
properties{ [业务字段]: 任意值 }—保存业务数据，拾取实体时读取

只画线或面时不需要传 position。position 只用于点、文字和图标的位置。

point 和 label 传什么 ​

对象字段类型或示例说明
pointpixelSize16点直径，单位 px
pointcolorColor.RED点填充色
pointoutlineColorColor.WHITE描边颜色
pointoutlineWidth3描边宽度
labeltext'地块 01'显示文字
labelfont'16px sans-serif'字体
labelfillColorColor.WHITE文字颜色
labeloutlineColorColor.BLACK文字描边色
labeloutlineWidth3文字描边宽度
labelpixelOffsetnew Cartesian2(0, -28)相对点位的屏幕偏移

polyline 传什么 ​

ts
{
  positions: Cartesian3.fromDegreesArray([经度1, 纬度1, 经度2, 纬度2]),
  width: 6,
  material: Color.CYAN,
  clampToGround: true,
}

positions 必填且至少包含两个坐标点。width 是像素宽度，material 是颜色，clampToGround 控制是否贴地。

polygon 传什么 ​

ts
{
  hierarchy: Cartesian3.fromDegreesArray([
    经度1, 纬度1,
    经度2, 纬度2,
    经度3, 纬度3,
  ]),
  material: Color.GREEN.withAlpha(0.45),
  outline: true,
  outlineColor: Color.GREEN,
  height: 0,
  extrudedHeight: 300,
}

hierarchy 必填且至少包含三个边界点。Cesium 会自动连接最后一个点和第一个点。height 是面离地高度；只有需要立体拉伸时才传 extrudedHeight。

load(entity) 会返回创建完成的原生 Entity；组件 ref 的 getEntity() 也可获取实例。坐标、点线面样式和显隐变化都会同步更新，组件卸载时只移除自身创建的 Entity。

CesiumDropMarker：业务点位列表 ​

vue
<CesiumDropMarker
  ref="markerRef"
  :points="markerPoints"
  :label-style="{ pixelOffset: [0, 48], outlineColor: '#ff551e' }"
  @click="onMarkerClick"
  @position-update="popupPosition = $event"
/>
ts
const markerPoints = [{
  id: "site-001", longitude: 116.4074, latitude: 39.9042,
  text: "北京站点", status: "online",
}];
名称类型默认值说明
pointsMarkerPoint[]必填原始业务点位数组
defaultImagestring内置图标默认 Marker 图片
iconWidth / iconHeightnumber32 / 47图标尺寸
showLabelbooleantrue是否显示文字
labelStyleMarkerLabelStyle{}全局标签样式
  • click(point, screenPosition) 返回原始点位和屏幕坐标。
  • position-update(screenPosition) 在相机变化时更新弹窗位置。
  • clearSelection() 清除当前选中 Marker。

弹窗属于业务 UI，应由使用方根据屏幕坐标渲染。

useEntityManager：命令式批量管理 ​

ts
const manager = useEntityManager({ viewer: viewerRef });

manager.addEntity({
  id: "point-1",
  longitude: 116.4,
  latitude: 39.9,
  point: { pixelSize: 10 },
});
manager.updateEntity("point-1", { longitude: 121.5 });
manager.removeEntityById("point-1");
manager.clearAll();
方法返回说明
addEntity(options)Entity | null添加实体；ID 冲突时替换旧实体
updateEntity(id, partial)boolean更新位置或展示属性
removeEntityById(id)boolean删除本管理器创建的实体
clearAll()void清空本管理器实体，不影响其他组件
getEntityById(id)Entity | undefined按 ID 查询
getAllEntities()Entity[]获取当前实体快照
