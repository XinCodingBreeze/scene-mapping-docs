3D Cesium 快速开始 ​

3D 模块使用 Cesium Viewer 渲染全球场景，提供影像、实体、业务 Marker、动态墙、3D Tiles，以及相机、拾取和实体批量管理能力。

推荐导入入口 ​

ts
import {
  CesiumMap,
  CesiumImagery,
  CesiumEntity,
  useCamera,
} from "scene-mapping-gis/3d";
import "scene-mapping-gis/dist/style.css";

scene-mapping-gis/3d 会加载 Cesium，仅建议在确实使用三维场景的页面中导入。

最小示例 ​

vue
<template>
  <div class="scene-container">
    <CesiumMap :ion-token="ionToken" @load="onViewerReady" @error="onError">
      <CesiumImagery
        type="xyz"
        url="https://server.arcgisonline.com/arcgis/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}"
      />
      <CesiumEntity
        :longitude="116.4074"
        :latitude="39.9042"
        :height="200"
        name="北京"
        :point="{ pixelSize: 14, color: Color.RED }"
        :label="{ text: '北京', fillColor: Color.WHITE }"
      />
    </CesiumMap>
  </div>
</template>

<script setup lang="ts">
import { Color } from "cesium";
import { CesiumMap, CesiumImagery, CesiumEntity } from "scene-mapping-gis/3d";
import type { Viewer } from "cesium";

const ionToken = import.meta.env.VITE_CESIUM_ION_TOKEN;

function onViewerReady(viewer: Viewer) {
  console.log("Viewer 已就绪", viewer);
}

function onError(error: Error) {
  console.error("Cesium 初始化失败", error);
}
</script>

<style scoped>
.scene-container { width: 100%; height: 600px; }
</style>

Cesium 静态资源 ​

Cesium 的 Workers、Assets、Widgets 和第三方资源必须能从浏览器访问。本项目的 demo-3d.vite.config.ts 已提供完整示例：

  1. 定义 CESIUM_BASE_URL，例如 /cesium/。
  2. 开发环境将 /cesium/* 映射到 node_modules/cesium/Build/CesiumUnminified/。
  3. 生产构建时将对应目录复制到部署站点的 /cesium/。

如果 Worker、wasm 或纹理出现 404，优先检查该配置，而不是组件 Props。

本地完整示例 ​

bash
npm run dev:3d

项目中的 demo-3d/App.vue 包含影像、Entity、业务 Marker、动态墙、相机飞行和屏幕事件的组合示例。

坐标约定 ​

ts
type CesiumPositionInput =
  | { longitude: number; latitude: number; height?: number }
  | [longitude: number, latitude: number, height?: number];

经纬度使用角度，高度使用米。相机 API 中的 heading、pitch、roll 也使用角度，工具内部会转换为 Cesium 所需的弧度。
