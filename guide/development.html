本地开发 ​

安装依赖 ​

bash
npm install

常用命令 ​

命令用途
npm run dev:2d启动完整 2D Demo，默认端口 5175
npm run dev:3d启动完整 3D Cesium Demo
npm run docs:dev启动 VitePress 文档站
npm run docs:build静态构建文档
npm run docs:preview预览文档构建产物
npm run docs:deploy构建并发布到 GitHub Pages
npm run typecheckVue 与 TypeScript 类型检查
npm run build构建 npm 组件库

编写可运行示例 ​

Leaflet 只能在浏览器运行。本文档的公开示例组件先渲染占位容器，在 onMounted 后异步加载真正使用地图源码的 *Inner.vue。新增示例时应延续该模式，确保 npm run docs:build 的 SSR 阶段不会执行 Leaflet。

文档通过 @scene-2d 别名直接引用 src/2d，所以交互示例反映当前工作区源码，而不是旧的 dist 产物。

发布前检查 ​

bash
npm run typecheck
npm run docs:build
npm run build

不要把天地图 Key、Cesium Token 或业务接口凭证写进 Markdown、示例组件和提交记录。
